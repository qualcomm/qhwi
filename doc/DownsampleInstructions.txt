Instructions for Downsample test app:

System Requirements:  -----------------------------------------------------------
Waipo or newer to run 
Kailua or newer with latest drivers to run with VK_QCOM_Image_Processing extension (see --shader-type command line parameter below)


Application Installation: -----------------------------------------------
adb install -t -g app-release.apk


Image file(s) installation ----------------------------------------------
Note:  If you skip this step or if the image file name is not specified as a command line argument, a test pattern will appear instead.
adb push example.jpg //sdcard/Android/data/com.qualcomm.qhwi_test/files/.


Running with command line options: ---------------------------------------
adb shell am start -n com.qualcomm.qhwi_test/android.app.NativeActivity -e cmdLine "'--tests=qcom_image_proc --debug=false --display-mode=0 --image-file=example.jpg'"
Note that command line options --tests=qcom_image_proc and --debug=false are necessary for this example.

Checking log: ------------------------------------------------------------
Each time the program is run, it appends an entry to a log file with details about the options and downsampling time.  Note that the default shader does not use VK_QCOM_Image_Processing (see --shader-type below) so it will be slower:
To get this file on your computer, use the following command line:
adb pull //sdcard/Android/data/com.qualcomm.qhwi_test/files/data_log.txt
Then load data_log.txt into your favorite text editor


Command line options: ----------------------------------------------------

--kernel-type=1 

0 = triangle
1 = Gaussian
2 = Mitchell-Netravali

--kernel-dim=8

Dimensions of weight kernel in pixels.  Must be even.

--downscale-factor=4 

Each successive downsampled image will be (w/downscaleFactor,h/downscaleFactor) in pixels.  Recommendation is for this to be roughly half of kernel-dim but nearby values may work well.  The larger this value, the fewer steps are required to reach thumbnail size.

--thumbnail-width=255 
--thumbnail-height=191 

Desired dimensions of smallest downsized image.

--display-mode=1 

0 = Show images left to right from smallest to largest (as many as will fit on screen) 
1 = Show images in sequence.  See also frame-hold and image-steps

--frame-hold=120 

How many screen frames to hold the display of a given image before switching.  Assume device has frame rate of 60 fps, so hold time in seconds is this number divided by 60.  Only has an effect if display-mode=1.

--image-steps=100

How many downsample steps to show, starting with the smallest one, when display-mode=1.  Any value larger than the actual number of steps will show all steps. 

--shader-type=1

1 = hlsl shaders with simulated VK_QCOM_Image_Processing
2 = glsl shaders with simulated VK_QCOM_Image_Processing
3 = glsl shaders with actual VK_QCOM_Image_Processing extension (requires Snapdragon 8 Gen 2 (Kailua) or newer GPU with updated drivers)
 
--image-file=test1.jpg

name of image file to load.
